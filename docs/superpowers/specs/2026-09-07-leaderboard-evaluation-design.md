# OnSite 大项排行榜与评测图片改版设计

## 目标

参考 Waymo Sim Agents 2024 排行榜的信息密度，调整 OnSite 2026 第五赛道页面。排行榜仅展示评测大项，不展示细分指标。评测流程直接使用用户从 PPT 提供的两张原图，删除现有网页重绘版本，并精简图片周边的小字说明。

## 排行榜

排行榜采用单层表头，每支队伍展示以下字段：

- 测试有效性总分。
- 图像/视频生成质量。
- 二维轨迹质量。
- 图像—轨迹一致性。
- 自动驾驶算法测试有效性。
- 基础门槛通过率。
- 提交时间。
- 成绩记录。

所有大项使用 0–100 的演示分数，数值越高越好。基础门槛显示比例数字，例如 `98.6%`，不再显示“通过/未通过”，所有演示记录均保留可查看的成绩。提交时间精确到日期与分钟。表头采用 Waymo 式克制浅色样式，不复制用户参考图的深色分组表头。桌面端完整展示，窄屏沿用表格内部横向滚动。

测试有效性总分继续作为主榜默认排序依据。演示数据、CSV 导出、成绩摘要和证书继续保持“演示数据”边界。

## 自由排序

排行榜采用 Waymo 式表头排序交互。排名、队伍/模型、测试有效性总分、四项大类分数、基础门槛通过率和提交时间均可点击排序，“成绩记录”不参与排序。

- 默认按测试有效性总分降序，活动表头使用 OnSite 品牌蓝背景并显示向下箭头。
- 非活动表头保持浅色背景，不显示箭头。
- 点击非活动表头后，该列成为活动列。数值和时间列首次按降序排列，队伍/模型首次按升序排列。
- 再次点击活动表头时，在升序与降序之间切换，并同步箭头方向。
- 排序只改变行的显示顺序，记录中的官方排名数字保持不变。
- 表头按钮支持键盘操作，活动列通过 `aria-sort` 暴露升降序状态。

## 评测图片

在“评测办法”区域加入两个独立图片模块：

1. **评测框架**：使用用户提供的 PPT 原图，展示“基础门槛评测、Agent 接入与评测、测试有效性得分”。
2. **评测闭环**：使用用户提供的 PPT 原图，展示从模型开发到回放测试、综合评价和得分反馈的闭环。

两张图片保持原始比例，桌面端占满正文宽度，移动端允许在图片容器内横向滚动，避免压缩到难以阅读。图片使用准确的替代文字，不重复显示图中已有标题。删除上一版 `.evaluation-framework` 与 `.evaluation-loop` 网页重绘结构和样式。

## 页面精简

- 删除封面下方的小字说明栏，包括“原创场景视觉 · AI 生成”。
- 删除多视角图片的方向小标签和 AI 说明文字。
- 保留排行榜“演示数据”声明、正式规则说明及页脚赛事边界，避免把演示结果误认为正式成绩。
- 减少评测图片周边边框和重复标题，以留白区分内容。

## 数据与代码范围

- `src/page.html`：更新排行榜表头、替换两个流程模块为图片并删除指定小字。
- `src/styles.css`：恢复简洁表头，增加评测图片布局并删除重绘流程样式。
- `src/results.js`：将演示数据改为四项大类分数、基础门槛通过率和提交时间，并更新 CSV 输出。
- `src/app.js`：同步成绩摘要，不引入新依赖。
- `public/`：保存用户提供的两张 PPT 原图。
- `scripts/`：先更新会失败的结构和浏览器断言，再完成页面实现并更新独立 HTML。

## 验证标准

- 排行榜只显示四项大类分数、总分、基础门槛通过率、提交时间和成绩记录。
- 不显示 FID、FVD、TTC 等小项分数。
- 两张 PPT 原图均出现在独立构建后的 `index.html` 中并内嵌为数据资源。
- 页面中不存在上一版网页流程结构及指定小字说明。
- 1440px 与 375px 视口无页面级横向溢出，排行榜和评测图片可在自身容器内横向滚动。
- 排序、搜索、CSV、PNG 证书及 PDF 打印保持可用。
- 每个可排序表头均能成为活动列，同列连续点击可切换升降序，非活动列不显示箭头。
- `npm run build`、`npm test`、`npm run test:browser` 全部通过。

## 非目标

- 不实现正式成绩后台、登录、提交或评测服务。
- 不在排行榜中加入任何细粒度诊断指标。
- 不新增框架、图表库或动画系统。
