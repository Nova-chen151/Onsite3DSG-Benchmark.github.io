# OnSite 三维场景生成首屏重设计

## 背景

当前项目是一个静态 HTML 页面，已经包含排行榜、参赛要求、评测办法和成绩证明等完整内容。用户希望首页首次打开时先呈现一张接近参考图的超大视觉，并将顶部品牌替换为 OnSite 标志。

## 目标

- 让首屏在桌面端占据主要视口，第一眼形成“进入驾驶世界”的沉浸感。
- 使用现有 `public/onsite-logo.svg` 作为顶部品牌标志。
- 使用一张专门为页面生成的浅色、高留白、抽象道路/流线视觉作为 hero 背景，避免文字与细节冲突。
- 保留现有页面的排行榜、成绩查找、导出和锚点导航能力。
- 在移动端保持文字可读、图片不裁切到关键信息，并支持 `prefers-reduced-motion`。

## 视觉方案

- 顶部导航使用白色半透明层和细边框，左侧为 OnSite 标志，右侧保留现有锚点导航与成绩入口。
- Hero 使用全宽、接近视口高度的浅色场景图；背景叠加很轻的渐变以保证标题对比度。
- 标题居中，包含 `OnSite Challenge 2026`、`三维场景生成` 和 `3D Scene Generation`，视觉层级接近参考图。
- 底部提供“查看排行榜”入口和向下滚动提示，保持功能可达而不过度增加营销内容。
- 进入动效只作用于文字和操作入口，使用短时的 opacity/transform 过渡；减少动画模式下关闭位移动画。

## 技术实现

- 在 `public/` 增加不含文字的 hero 背景图，使用 `object-fit: cover` 响应式铺满。
- 调整 `src/page.html` 的 hero 结构，使标题与操作入口在视觉中心，保留语义化标题和跳过链接。
- 重写 `src/styles.css` 中的 header、hero 和响应式规则，不改变排行榜与对话框功能样式的行为。
- 为 logo、hero、导航和 CTA 保留明确的焦点样式与替代文本。

## 验收标准

1. 桌面端首次打开即可看到大面积的浅色 hero 视觉，OnSite logo 位于顶部。
2. 标题在浅色背景上清晰可读，hero 高度接近视口高度，页面无需先滚动才能看到主要识别信息。
3. “查看排行榜”可以跳转到现有排行榜区块；原有“我的成绩”和成绩导出交互不受影响。
4. 760px 以下视口下布局不横向溢出，标题、导航和 CTA 可读可点。
5. HTML 检查、数据测试和浏览器检查通过。
